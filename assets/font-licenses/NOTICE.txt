Font licences — Ivory
=====================

Ivory's executable statically embeds six font files. This folder holds the
licence texts for the four that arrive with eframe/egui's `default_fonts`
feature (the `epaint_default_fonts` crate). Courier Prime, Ivory's own UI
typeface, is covered by OFL.txt, which ships next to the Courier Prime TTFs.

The SIL Open Font License and the Ubuntu Font Licence both require the
copyright notice to accompany the licence text. The upstream files as shipped
by `epaint_default_fonts` carry no copyright line, so the notices are
reproduced here verbatim from each font's own `name` table.
